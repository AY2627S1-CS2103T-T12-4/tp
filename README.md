# TAssist

**TAssist is a desktop app for CS2040S teaching assistants (TAs) to track their students' tutorial attendance, class participation and assignment results.** It is optimised for TAs who type fast: almost everything is done by typing short commands, so records can be updated live during a tutorial, faster than with paper sheets or a mouse-driven web portal.

With TAssist, a TA can:

* manage several **tutorial groups** and switch between them with one command
* keep a **student roster** for each group
* record **weekly attendance** (present / absent) and see at a glance who has not been marked
* give **weekly participation scores** (0 to 5)
* track **assignment submissions and grades** (0 to 100), and see who has not submitted
* get **in-app help** on every command, without needing an internet connection

All data is saved automatically on the TA's own computer after every change.
